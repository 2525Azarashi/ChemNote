## 見つかった問題と修正候補

1. **待機中に退出しても部屋が閉じない**
   - 本体ではホスト退出後も合言葉で新規参加できました。
   - 候補では待機中の退出をトランザクションで `aborted` にし、対戦開始との競合も再確認します。
2. **対戦中の明示的退出で早期決着しない**
   - 本体では退出を表示しても終了判定が最終問待ちでした。
   - 候補ではサーバ確定済みの退出で勝敗を決め、終了後の再読み込みでも結果を維持します。ルールも退出証拠がある場合だけ早期決着を許可します。
3. **2人が同時に全国待機すると、両方が待ち続ける場合がある**
   - 先に検索してから待機票を置く順序が原因でした。
   - 候補では先に待機票を置き、双方の票を同じトランザクションで確認・消費します。二重の部屋作成も防ぎます。
4. **結果を再読み込みすると再申告し、未処理エラーになる**
   - 候補では既存の本人の申告があれば再送しません。送信失敗も未処理例外にしません。

退出時に、まだ解いていない問題まで弱点として記録しないための選別も候補に含めました。
