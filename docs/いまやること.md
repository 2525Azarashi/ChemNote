# よくある質問

### Q. 「索引（インデックス）をデプロイ」って前に言われたけど？

**やらなくて大丈夫です。**

前回の説明で `firebase deploy --only firestore:indexes` というコマンドを
お伝えしましたが、これは**パソコンに開発ツールを入れないと使えません**。

そこで**索引が無くても動くようにプログラム側を直しました。**
（＝いつもの「スクリプト側を変える」作戦です）

そのため、今回は**ルールの貼り替えだけ**で全国対戦もフレンド対戦も動きます。

**根拠**（Firebase 公式ドキュメントで確認しました）:

> Firestore は**条件が1つだけの検索**なら、索引を**自動で作ってくれます**。
> 手で作らないといけないのは「条件を組み合わせた検索」だけです。
> 今回のプログラムは、その組み合わせをやめて**条件1つの形に書き換え**ました。

出典：<https://firebase.google.com/docs/firestore/query-data/index-overview>
（"Single-field indexes ... created automatically" / `array-contains` と `==` は自動索引の対象）

> なお `firestore.indexes.json` に索引の宣言自体は入れておきました。
> 将来パソコンに開発ツールを入れたときに使えます。
> **今は入れなくても動きます。**
